# Native showcase capture

The documentation image is the complete real Tauri window, including its native
Windows title bar. The portfolio image uses one continuous crop from that
application's live ledger, with an external brand header and frame. The crop
removes the inspector, title bar and footer. No app controls, files, successful
results or numbers are painted in or substituted.

## Reproduce

Use Windows with the repository's pinned pnpm dependencies, Rust toolchain,
Playwright Chromium, Python with Pillow, and a compatible local FFmpeg/ffprobe
pair. Close Morflo before starting. Captures use a temporary process-local
WebView2 debugging endpoint and leave no production debugging setting behind.

The current native and portfolio captures use application source `fab497c`
(0.3.0), Windows at 150%
scale, local FFmpeg 8.1.2 and Pillow 12.3.0. The installed executable's SHA-256
matches the captured executable; the full hash is in `showcase-provenance.json`.
The earlier before/after composition study remains evidence from Gate 11
(`b93f4a1`); the primary screenshots were refreshed after batch recovery.

The captured application's frontend Git tree is
`cd6635d041f2583f379ad8bcbb16509a8d98c7b8`; its native source tree is
`a488ce3a2924c5671c47040b7fd800adc836fb04`. Compare these with
`git rev-parse HEAD:src HEAD:src-tauri` to identify the same application sources
independently of subsequent documentation or source-publication commits.

```powershell
pnpm install --frozen-lockfile
pnpm samples:showcase
pnpm package
pnpm capture:showcase final
python scripts/compose-showcase.py --capture work/showcase/final --out docs/assets/ledger
pnpm test:native:ledger:windows
```

`capture-ledger.mjs` creates a fresh media directory on each run, selects Easy to
share for the two opaque images and Keep transparency for the botanical image,
converts through the application's actual controls, checks source hashes, probes
actual outputs and captures light/dark and ordinary/minimum window sizes. It
also asserts that queued/completed row heights differ by no more than one pixel.
It records the Git source commit, executable hash, sample hashes, output hashes,
dimensions, pixel format and actual receipt. Use a built executable from that
source commit; source-only edits after compilation are not captured changes.

`capture-native-window.ps1` targets only the launched Morflo process's own
window, adjusts the client dimensions for the observed DPI and uses PrintWindow
with the native frame bounds. It does not take a desktop screenshot. Client
captures use WebView2. Current native evidence is at 150% Windows scale; browser
checks additionally cover 100%, 125% and 150% rendering, themes and keyboard use.

The alternate bottom-workbench composition is an explicitly temporary CSS study
in the capture script. The selected composition and final screenshots use the
shipped application styles. The image composer uses uniform Lanczos resizing;
`showcase-provenance.json` records the crop, placement and source hashes.

## Sample provenance

The three samples are original procedural illustrations authored for Morflo,
generated by `scripts/generate-showcase-samples.mjs` from its checked-in SVG
geometry. They use no third-party photographs, generated-image service or remote
asset. They share this project's `MIT OR Apache-2.0` license.

| Sample               | Original dimensions | Job               | Observed output                               |
| -------------------- | ------------------- | ----------------- | --------------------------------------------- |
| Coastal morning.png  | 2400 × 1600         | Easy to share     | JPEG, 1920 × 1280, about 51 KB, 84.6% smaller |
| Citrus study.png     | 1800 × 2200         | Easy to share     | JPEG, 1571 × 1920, about 60 KB, 93.5% smaller |
| Botanical cutout.png | 1200 × 1200, alpha  | Keep transparency | PNG, 1200 × 1200, about 77 KB, 1.1% larger    |

These are measurements of these exact illustrations on the observed local
engine, not a general compression promise. The built-in engine can produce
different sizes. The PNG suffix `(2)` demonstrates source-safe output naming.
All three original hashes remain unchanged.

## Delivered files and portfolio handoff

All assets are under `docs/assets/ledger/`:

- `before-native.png`: unmodified baseline application with actual results.
- `native-window.png`: complete upgraded native window, no crop.
- `queued.png` and `dark.png`: actual pre-conversion and dark-theme captures.
- `native-960x640.png` and `native-780x620.png`: unaltered client captures at the
  supported smaller sizes, with the inspector below the ledger.
- `composition-a.png` and `composition-b.png`: the working layout comparison.
- `recovery-native.png`: unretouched client capture from the installed native
  recovery test. Eighteen real conversions succeeded, two sources were deliberately
  moved after inspection, and a separate synthetic damaged input failed inspection.
  Restoring the moved sources and preparing retries subsequently completed both;
  the damaged input remained failed. This is an error-recovery demonstration,
  not a simulated successful conversion. It uses the same source and executable
  as the current showcase, with numbered copies of the owned illustrations.
- `morflo-1200x750.png`: composed portfolio image.
- `morflo-480x300.png` and `morflo-320x200.png`: inspected display-size derivatives.
- `showcase-provenance.json`: source/crop/output evidence and composition record.
- `ledger-detail.png`: the unaltered continuous crop used by the composer.

Prepared for a separate portfolio website handoff; no sibling repository was
modified. Suggested alt text: **Morflo's local conversion ledger pairs each source
image with its actual output, dimensions and measured size change, including a
larger transparent PNG.** Use the 1200 × 750 file with the two matching derivatives
as responsive sources. The native-window image is the full documentation view.

## Evidence limits

This host has a persistent local FFmpeg installation. Native showcase and batch
tests use that engine, while the existing Rust native-image tests and
capability-specific UI tests cover engine-free behavior. Unavailable-video setup
is tested as an explicit UI fixture, not falsely described as a clean Windows
installation. No current macOS or Linux native-window capture is claimed.
Unsigned local builds are used. This work does not publish a release or change
the application's version or distribution eligibility.
