# Security

Morflo processes local files and protects source immutability, safe output
publication and a narrow frontend permission boundary. Report suspected
vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/snowyukitty/morflo/security/advisories/new).
If that facility is unavailable, open an issue asking for a private reporting
channel without including vulnerability details or exploit material.

Include the affected source version, operating system, engine version, impact
and minimal reproduction. Prefer synthetic files. Do not send personal media,
credentials, absolute paths or unrelated diagnostic data.

Security fixes target the current development line. There is no published
long-term support or response-time guarantee. Public installer releases are
not yet available; check the [README](README.md) for current distribution status.
External media-engine binaries have their own maintenance and trust boundaries.
